VIO BULZ COACHING — GITHUB PAGES
================================

CE CONȚINE:
- index.html — pagina principală
- onboarding.html — formularul „Alege-ți procesul”
- style.css — stilul formularului
- config.js — AICI se pun linkurile Stripe și endpoint-ul formularului
- script.js — conectează butoanele la linkurile din config.js
- Vio_Bulz_Ghid_Complet_Fitness_Coaching_ONLINE_COPERTA_FINALA.pdf — ghidul digital

IMPORTANT:
1. Site-ul este static și poate fi publicat gratuit cu GitHub Pages.
2. Butoanele de plată sunt pregătite, dar NU inventăm linkuri Stripe.
3. În config.js trebuie introduse ulterior linkurile Stripe reale.
4. Formularul este pregătit pentru un endpoint de formulare; până îl conectăm, validează datele local.
5. Recenziile nu sunt fabricate. Secțiunea conține locuri marcate pentru recenzii reale.

PUBLICARE PE GITHUB:
1. Intră în repository-ul „vio-bulz-coaching”.
2. Apasă „Add file” → „Upload files”.
3. Încarcă TOATE fișierele și folderul/fișierul PDF din acest pachet.
4. Asigură-te că index.html este în rădăcina repository-ului.
5. Commit changes.
6. Repository → Settings → Pages.
7. La „Build and deployment”, alege „Deploy from a branch”.
8. Branch: main / folder: /(root).
9. Save.
10. GitHub îți va afișa adresa gratuită de tip:
   https://viorel...github.io/vio-bulz-coaching/

NU șterge repository-ul și nu modifica numele fișierului index.html.
